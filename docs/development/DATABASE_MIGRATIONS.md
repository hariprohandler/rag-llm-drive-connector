# Database Migrations Guide

This document provides guidance on database migrations using Alembic.

## Running Migrations

### Apply All Migrations

```bash
# Using alembic
alembic upgrade head

# Using Make
make migrate
```

### Create New Migration

```bash
# Auto-generate migration from model changes
alembic revision --autogenerate -m "Description of changes"

# Create empty migration
alembic revision -m "Description of changes"
```

### Rollback Migration

```bash
# Rollback one version
alembic downgrade -1

# Rollback to specific revision
alembic downgrade <revision_id>
```

## Best Practices

1. Always review autogenerated migrations
2. Test both upgrade and downgrade paths
3. Use descriptive migration messages
4. Keep migrations focused on single logical changes
5. Never modify existing migrations (create new ones instead)

For detailed information, see the [migrations README](../migrations/README.md) in the migrations directory.
